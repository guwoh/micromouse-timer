# Mã nguồn Micromouse Timer

Chạy app từ thư mục này:

```bash
python -m app.main
```

Cài phụ thuộc và kích hoạt môi trường trước khi chạy. Tài liệu chính đã được tập trung tại thư mục gốc repo:

- [Giới thiệu, cài môi trường và cấu trúc dự án](../README.md)
- [Sử dụng camera, mock video, ROI và phiên thi](../docs/usage.md)
- [Phát triển và kiểm thử](../docs/development.md)
- [Đóng gói và cài Windows/Linux](../docs/packaging.md)

`exports/`, `logs/`, `preferences.json`, `build/` và `dist/` là dữ liệu local được Git bỏ qua.
